# ユーザーテンプレート

このディレクトリでは、デフォルトのSpec Workflowテンプレートを上書きするカスタムテンプレートを作成できます。

## カスタムテンプレートの使用方法

1. **カスタムテンプレートファイルを作成** - 上書きしたいデフォルトテンプレートと全く同じ名前でこのディレクトリにファイルを作成します：
   - `requirements-template.md` - 要件ドキュメントテンプレートを上書き
   - `design-template.md` - 設計ドキュメントテンプレートを上書き
   - `tasks-template.md` - タスクドキュメントテンプレートを上書き
   - `product-template.md` - プロダクトステアリングテンプレートを上書き
   - `tech-template.md` - 技術ステアリングテンプレートを上書き
   - `structure-template.md` - 構造ステアリングテンプレートを上書き

2. **テンプレート読み込みの優先順位**：
   - システムはまずこの `user-templates/` ディレクトリをチェックします
   - ここに一致するテンプレートが見つかった場合、それが使用されます
   - それ以外の場合、`templates/` のデフォルトテンプレートが使用されます

## カスタムテンプレートの例

カスタム要件テンプレートを作成するには：

1. このディレクトリに `requirements-template.md` という名前のファイルを作成します
2. カスタム構造を追加します。例：

```markdown
# 要件ドキュメント

## エグゼクティブサマリー
[カスタムセクション]

## ビジネス要件
[カスタム構造]

## 技術要件
[カスタムフィールド]

## カスタムセクション
[ワークフロー固有のセクションを追加]
```

## テンプレート変数

テンプレートには、ドキュメント作成時に置換されるプレースホルダーを含めることができます：
- `{{projectName}}` - プロジェクト名
- `{{featureName}}` - 指定される機能名
- `{{date}}` - 現在の日付
- `{{author}}` - ドキュメントの作成者

## ベストプラクティス

1. **デフォルトから始める**： `../templates/` からデフォルトテンプレートをコピーして開始点とする
2. **構造の一貫性を保つ**： ツールとの互換性のため、類似のセクションヘッダーを維持する
3. **変更を文書化**： セクションが追加/変更された理由をコメントで説明する
4. **バージョン管理**： カスタムテンプレートをバージョン管理で追跡する
5. **十分にテスト**： カスタムテンプレートがSpec Workflowツールで動作することを確認する

## 注意事項

- カスタムテンプレートはプロジェクト固有であり、パッケージ配布には含まれません
- `templates/` ディレクトリには、各バージョンで更新されるデフォルトテンプレートが含まれています
- このディレクトリのカスタムテンプレートは、更新時に保持されます
- カスタムテンプレートにエラーがある場合、システムはデフォルトテンプレートにフォールバックします
