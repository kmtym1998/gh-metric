# Product Overview

## プロダクトの目的

gh-metricは、GitHubリポジトリにおける開発活動を定量的に可視化するためのCLI拡張機能です。

GitHub CLIが提供する生データは、そのままでは分析や集計が困難であるという課題を解決します。本ツールは、これらのデータを整形・演算・集計し、チームや個人が振り返りに活用できる形で提供することを目的としています。

現在はプルリクエストのリードタイム分析に特化していますが、将来的にはIssueやDiscussionの集計機能も追加し、開発生産性の包括的な可視化ツールとして進化させていく予定です。

## ターゲットユーザー

本ツールの主要なターゲットユーザーとその課題：

- **開発チームリーダー**
  - ペインポイント：チームの生産性を定量的に把握できず、改善点が不明確
  - ニーズ：チームメンバーのボトルネックを特定し、効率的なサポートを提供したい

- **エンジニアリングマネージャー**
  - ペインポイント：GitHub CLIの生データは整形や集計が大変で、KPI追跡が困難
  - ニーズ：定期的な振り返りのために、すぐに使える形式でメトリクスを取得したい

- **個人開発者**
  - ペインポイント：自身のコントリビューション効率を客観的に評価できない
  - ニーズ：自己改善のための具体的な指標と傾向を把握したい

## 主要な機能

1. **PRリードタイム分析**: 最初のレビュー、承認、マージまでの時間を自動計測し、ボトルネックを特定
2. **柔軟なデータ整形**: 期間指定、ユーザーフィルタリング、週末除外など、振り返りに適した形でデータを整形
3. **多様な出力形式**: JSON/CSV形式での出力により、スプレッドシートや他の分析ツールとの連携を容易に

### 今後追加予定の機能

- **Issue分析**: Issueの解決時間、ラベル別の傾向分析
- **Discussion集計**: ディスカッションの活発度、参加者分析
- **統合レポート**: PR、Issue、Discussionを横断した総合的な生産性レポート

## 成功指標

本プロダクトは状態目標として以下の達成を目指します：

- **データアクセシビリティ**: GitHub CLIの生データを、振り返りにすぐ使える形式で提供できている状態
- **分析の網羅性**: PR分析に加え、Issue・Discussionの集計機能が実装され、開発活動全体を可視化できる状態
- **ユーザー体験**: コマンド1つで必要なメトリクスを取得し、チームや個人の振り返りに即座に活用できる状態

## プロダクトのコア原則

1. **シンプルさ優先**: CLIツールとして、複雑な設定なしに即座に使える設計を維持
2. **実用的な出力**: 生データではなく、振り返りや分析にすぐ使える形式でデータを提供
3. **ニーズドリブンな拡張**: 必要に応じて柔軟にメトリクスを追加し、ユーザーの課題解決を優先
